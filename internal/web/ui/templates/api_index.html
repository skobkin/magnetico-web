API documentation

Public reference for the interfaces of this Magnetico instance.

API v2

The JSON API and the RSS feed for new integrations.

Torrent search, torrent details and the file list of a torrent, authenticated with an API token in the Authorization: Bearer header. The v2 RSS feed uses a separate RSS token.

API v1 deprecated

Only the legacy RSS feed is kept.

The old feed address keeps working for existing torrent clients and may be removed in a future release. The old login and JSON endpoints no longer exist.

Tokens are created on your account page after signing in; they are shown once. These pages never contain a token, and nothing you type into them is stored. The interactive "Try it out" feature sends only GET requests to this server, with the token you paste into the Authorize dialog.
