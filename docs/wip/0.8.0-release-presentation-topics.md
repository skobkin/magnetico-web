# Topics for the future 0.8.0 release presentation

**Status:** a list of topics only. The presentation itself is not created in task 07J. Each topic names where the evidence is; claims must be tied to those sources and to the measurement context given there.

1. **Unified Go architecture.** One codebase and one executable with `crawl`, `ingest`, `web`, `migrate` and `dev`; the PHP runtime is gone; separately deployed services. ([`docs/projects_differences.md`](../projects_differences.md) §3)
2. **Compact file-list storage and the measured storage savings.** One versioned blob per torrent, codec profiles, single-file torrents with no blob. The real-data figure is the 04B lab-sample run (17 GB source database, 2.9 GB target, "~5.9×"), quoted with its context: a database-size comparison, profile `compact`, not a codec ratio. ([`04B report`](04B-verification-recovery-report.md), `projects_differences.md` §4.2)
3. **Distributed durable ingestion.** Crawler-local SQLite WAL queue, authenticated HTTP delivery, PostgreSQL ingest queue with quota, single consumer, quarantine; several crawlers, one ingest. ([`06 results`](06-crawler-ingest-results.md))
4. **Ingest caching.** The plain LRU with permanent positive entries and 20 s negative entries, and why. ([`projects_differences.md`](../projects_differences.md) §5)
5. **Keyset pagination.** Opaque cursors in both directions, deterministic ties, stable under inserts (tested). ([`07E report`](07E-web-search-details-report.md), 07J search tests)
6. **`LIMIT n+1` without a result count.** No `COUNT(*)`, no `OFFSET`; what it buys and what the interface gives up.
7. **The adaptive file-browser architecture.** Backend-selected complete tree or paginated directories over one shared index, with hard size limits. ([`07F report`](07F-web-ui-report.md))
8. **Positional directory paths.** Addressing directories by position so no byte sequence has to survive a URL. (`web-v1.md` §6.4.8)
9. **Account and API improvements.** Private, invitation-only service; sessions and CSRF; API v2 with embedded OpenAPI 3.2 and a vendored Swagger UI; RSS v2 with its own token; separate credential types; suspend-not-revoke on disable; email recovery with verification, removal of an address and the explanation of unverified addresses. ([`07G report`](07G-web-account-api-report.md), 07J)
10. **Legacy compatibility and migration.** Offline, resumable `migrate torrents` and `migrate users`, two verifications, forensic export, v1 RSS and legacy tokens preserved, legacy hashes upgraded on first login. ([`04A`–`04D` reports](04D-end-to-end-validation-report.md), [`07H report`](07H-user-migration-report.md), [`docs/migration_0.8.0.md`](../migration_0.8.0.md))
