# Skips that are allowed in a CI run (ci/skipcensus). Format: test-name regexp <TAB> reason regexp <TAB> why.
# Every test skipped for any other reason (above all: no PostgreSQL) fails the run.
# Derived from a full `go test -json -p 3 ./...` run INSIDE the CI image (golang:1.27.4-alpine: no docker, no git, no gcc) against a
# disposable trust-auth PostgreSQL 17 (docs/wip/08-measurements/skip-census-ci-image.txt). A list taken from a developer VM is wrong:
# a test that finds docker there runs, and is missing here.
^Fuzz\w*/seed#\d+$	.*	a seed-corpus entry that the fuzz target rejects as invalid input (t.Skip inside the fuzz function)
^TestDumpBenchBlobs$	MAGNETICO_BLOB_DIR	opt-in: writes benchmark blobs
^TestMeasure$	MAGNETICO_CRAWLQUEUE_MEASURE_DIR	opt-in: crawl queue measurements
^TestE2EIngestMemoryProfile$	MAGNETICO_E2E_PROFILE_DIR	opt-in: ingest memory investigation
^TestE2ELargeRecordQualification$	MAGNETICO_E2E_EDGE_DIR	opt-in: large-record qualification
^TestE2EMultiCrawlerStress$	MAGNETICO_E2E_MULTI_DIR	opt-in: multi-crawler stress
^TestMarkBenchmarkDatabase$	MAGNETICO_BENCH_MARK	opt-in: marks a seeded benchmark database
^TestWebDemoServer$	MAGNETICO_DEMO_DIR	opt-in: interactive web demo server
^(TestColdBuildReport|TestMeasureComplexityLimits|TestMeasureTreeSize|TestWarmNavigationAllocations)$	MAGNETICO_BENCH_LARGE=1	opt-in: expensive measurements
^(TestMeasureSearchPlans|TestMeasureTOASTIdentityAndHeader)$	MAGNETICO_MEASURE=1	opt-in: storage measurements
^TestFrontendSelfTestsInBrowser$	MAGNETICO_TEST_BROWSER	opt-in: needs a Chromium binary
^(TestChildProcess|TestColdBuildChild|TestHostileNestingChild|TestHostilePeerChild|TestHelperNeedsDB|TestHelperLeftover)$	(child process helper|child of|helper of)	body of a subprocess helper: skips unless re-executed by its parent test
^TestOpenRefusesFsyncOff$	will not change fsync on an external server	KNOWN COVERAGE GAP of the external-server mode: needs a locally controlled cluster (docker or initdb)
^TestIdentitySameDatabaseViaSocketAndTCP$	no Unix socket directory	KNOWN COVERAGE GAP of the external-server mode: needs a locally controlled cluster (docker or initdb)
^TestSSLCertFileIsHonoured$	system roots were already initialised	order-dependent skip: the process initialised the system roots before the test; it is only effective when run in isolation
^TestFaultRestartedSourceIsNotDrift$	docker with a locally cached postgres:17 image is required	KNOWN COVERAGE GAP of CI: the restart scenario of finding F6(i) restarts a PostgreSQL container and needs the docker CLI, which the CI test image does not have (it runs on a developer machine)
^Test(ReleaseTagPicksTheNewestStableGoLineRelease|PrepareRebuild\w+)$	needs git and jq	the CI test image has neither; workflow-invariants installs both and runs these tests with REPOCHECK_REQUIRE_TOOLS=1
